# 15 — Glossary

| Term | Definition |
|---|---|
| Agency / Organisation | Enforcement body or tenant that owns operational records. |
| ANPR / ALPR | Automatic number-plate/license-plate recognition from image/video. |
| Appeal | Formal challenge to an issued notice or decision under configured rules. |
| Audit event | Attributable, timestamped record of a material action/change. |
| Candidate detection | Machine/source-generated event requiring validation; not a final violation decision. |
| Chain of custody | Documented evidence acquisition, handling, access, transfer, processing and disposal. |
| Challan / Notice | Formal notice/demand issued under applicable jurisdiction process. |
| Driver | Person established as operating the vehicle at event time. |
| Evidence asset | Original media/document or linked derivative supporting a case. |
| Fine assessment | Versioned calculation of an amount due for an approved violation. |
| Fine schedule | Authority-approved rule mapping offence/applicability to amount/calculation. |
| Jurisdiction | Legal/administrative area whose offence and enforcement rules apply. |
| Maker-checker | Separation requiring another authorised person to approve a sensitive action. |
| Notice reference | High-entropy public identifier used for limited notice lookup. |
| Registered owner | Person/entity recorded as owning a vehicle for a defined period; not necessarily driver. |
| RPO | Recovery Point Objective: maximum acceptable data loss measured in time. |
| RTO | Recovery Time Objective: target restoration time after disruption. |
| Tenant isolation | Preventing one organisation's users from accessing another organisation's data. |
| Violation | Case recording an alleged traffic offence and its review/outcome lifecycle. |
| VMS | Video Management System used by an authorised camera/source. |
| Webhook | Provider-initiated HTTP callback reporting an event such as payment status. |
